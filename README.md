# maxdomagk.de

Source for my personal website, built with [Quarto](https://quarto.org)
and a custom theme (light + dark). Deployed via Netlify.

## Structure

- `index.qmd` - About page
- `research/`, `publications/`, `presentations/` - content listings
- `theme-light.scss` / `theme-dark.scss` - theme customization
- `styles.css` - additional styling
